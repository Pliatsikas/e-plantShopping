# e-plantShopping

## Paradise Nursery

Paradise Nursery is a React-based shopping cart application for an online plant shop. The app lets users browse a variety of houseplants organized into categories, add them to a shopping cart, and manage their cart before checkout.

### Features

- **Landing page** with a company overview and a "Get Started" button linking to the product listing page
- **Product listing page** showcasing houseplants across multiple categories (e.g., Aromatic Plants, Medicinal Plants), each with a thumbnail, name, description, price, and an "Add to Cart" button
- **Shopping cart page** displaying each plant type in the cart with its thumbnail, unit cost, and subtotal, along with buttons to increase/decrease quantity or delete an item
- **Dynamic cart icon** in the navigation header showing a live count of items in the cart
- **Continue Shopping** and **Checkout** buttons on the cart page

### Tech Stack

- React (functional components and hooks)
- Redux Toolkit for state management
- CSS for styling

### Getting Started

1. Clone the repository:

git clone https://github.com/<your-username>/e-plantShopping.git

2. Install dependencies:

npm install

3. Run the development server:

npm run dev
